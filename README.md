# CVR Lost & Found — Student + Admin Demo

A simple frontend-only college lost-and-found project made with HTML, CSS and JavaScript.

## Run it
1. Extract this folder.
2. Open the folder in Visual Studio Code.
3. Install the **Live Server** extension if needed.
4. Right-click `index.html` and choose **Open with Live Server**.

## Demo details
- Student portal: enter any email and a password with at least 4 characters.
- Admin portal: choose **Open Admin Portal** on the sign-in screen.
- Reports and admin changes exist only in the current browser session.
- Photos are previewed in the browser only. They are not uploaded or stored.
- This is a classroom demonstration, not a secure live service. Do not use real passwords or sensitive contact details.
